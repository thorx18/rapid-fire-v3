1. What is Data Visualization?
Answer:

Data Visualization is the graphical representation of data using charts, graphs, and plots.
It helps in:

understanding data easily
identifying patterns and trends
comparing values visually
making better decisions from data analysis
2. Why is Data Visualization Important?
Answer:

Data Visualization is important because:

it simplifies complex data
helps detect trends and relationships
improves analysis and understanding
makes data more interactive and meaningful
supports decision-making processes

4. What is Pandas?
Answer:

Pandas is a Python library used for:

data manipulation
data analysis
handling tabular datasets

It works mainly with DataFrames and CSV files.

5. What is a DataFrame?
Answer:

A DataFrame is a two-dimensional tabular data structure in Pandas consisting of rows and columns, similar to an Excel sheet or database table.

6. What is CSV?
Answer:

CSV stands for Comma Separated Values.
It is a file format used to store tabular data in rows and columns.

12. What is Matplotlib?
Answer:

Matplotlib is a Python plotting library used for creating graphs, charts, and visualizations.

13. What is Seaborn?
Answer:

Seaborn is a statistical visualization library in Python built on top of Matplotlib.
It provides attractive and advanced graphical visualizations with simpler syntax.

14. Difference Between Matplotlib and Seaborn
Matplotlib	Seaborn
Basic plotting library	Advanced visualization library
More manual coding	Easier and cleaner syntax
Simple graphs	Statistical and attractive graphs
15. Why are Matplotlib and Seaborn used together?
Answer:

Seaborn is used for creating advanced visualizations, while Matplotlib is used for graph customization such as:

title
labels
figure size
displaying graphs
16. What is a Scatter Plot?
Answer:

A Scatter Plot is used to show the relationship between two numerical variables.

17. What is a Histogram?
Answer:

A Histogram shows the frequency distribution of continuous data.

18. What is a Bar Plot?
Answer:

A Bar Plot is used to compare values between different categories.

19. What is a Box Plot?
Answer:

A Box Plot displays:

median
quartiles
outliers
data distribution
20. What is a Violin Plot?
Answer:

A Violin Plot combines:

box plot
density distribution

to show data spread and distribution shape.

21. What is a Heatmap?
Answer:

A Heatmap is a graphical representation of correlation between variables using color intensity.

22. What is Correlation?
Answer:

Correlation represents the relationship between two variables.

Positive correlation → both increase together
Negative correlation → one increases while other decreases
23. What is Pairplot?
Answer:

Pairplot compares multiple numerical variables together using pairwise graphs.
